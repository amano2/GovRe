The Stale-Code Vulnerability in AI Guardrails

Enterprise LLM systems (e.g. NeMo Guardrails) enforce rules using hand-coded if/else logic. But company policies change constantly. When rules change, hardcoded code silently enforces obsolete policies until software engineers manually rewrite and redeploy software.

System A: Hand-crafted rule engine (sub-millisecond arithmetic baseline).
System B: FAISS dense retrieval + LLM Judge with verbatim citations.
System C: Hybrid Router (Tier 1 fast rules $\to$ Tier 2 retrieval fallback).
